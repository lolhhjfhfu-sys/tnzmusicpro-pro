tnzmusicpro
Ночной музыкальный сайт с настоящим локальным MP3-плеером.

Разделы: Главная, Моя волна, Мне нравится, Все песни, Новинки, Настроения,
История, Коллекции, Исполнители, Настройки.
Убраны разделы «В дорогу» и «Радио».

Можно менять:
- цвет интерфейса;
- обои;
- загружать свои обои;
- выбирать 3D/неон фон.

Музыка из доступных MP3 пользователя встроена в папку music.
